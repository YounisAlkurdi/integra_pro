# 🚀 خطة تنفيذ إصلاح وتطوير Integra (Execution Plan)

هذه الخطة مجزأة إلى مهام صغيرة لضمان تحويل المشروع إلى مستوى احترافي دون كسر الوظائف الحالية.

---

## الجزء الأول: البنية التحتية والأمن (Foundation & Security)
*الهدف: تأمين النظام وجعل الـ Backend أسرع وأكثر استقراراً.*

- [ ] **Task 1.1: ترقية الـ Backend لـ Async**
  - استبدال `urllib` بـ `httpx` في `nodes.py` و `payments.py`.
  - تحويل دوال `_supabase_request` لتكون `async`.
- [ ] **Task 1.2: إغلاق الثغرات الأمنية**
  - إزالة الـ Fallback في `auth.py`.
  - فرض التحقق من الـ Token في `get_livekit_token`.
- [ ] **Task 1.3: حماية الأسعار**
  - ربط `validate_price` بـ Stripe Products مباشرة بدلاً من ملف JSON.

---

## الجزء الثاني: تفتيت "الوحش الجافاسكريبت" (JS Modularization)
*الهدف: جعل الكود قابلاً للصيانة والتطوير.*

- [ ] **Task 2.1: إنشاء المكتبة المركزية `api-client.js`**
  - توحيد كل طلبات الـ fetch في مكان واحد مع معالجة أخطاء موحدة.
- [ ] **Task 2.2: تقسيم `integra-session.js`**
  - استخراج منطق `LiveKit` لملف مستقل.
  - استخراج منطق `MediaPipe` و `Forensic Tracker` لملف مستقل.
- [ ] **Task 2.3: تحديث الصفحات الأخرى**
  - إعادة بناء `dashboard.js` و `reports.js` لاستخدام المكتبة الجديدة.

---

## الجزء الثالث: تحسين تجربة المستخدم والأداء (UI/UX & Perf)
*الهدف: جعل المنصة سريعة وتعمل بكفاءة عالية.*

- [ ] **Task 3.1: إعداد بيئة Tailwind الاحترافية**
  - تثبيت Tailwind CLI وإلغاء رابط الـ CDN.
- [ ] **Task 3.2: تحسين أداء المعالجة الجنائية**
  - نقل عمليات الـ Tracker إلى `Web Worker` لمنع تجمد المتصفح أثناء المقابلة.
- [ ] **Task 3.3: إكمال الوظائف الناقصة**
  - تفعيل زر "تحميل الفاتورة" في صفحة `billing.html`.
  - إضافة واجهة "المعايرة" (Calibration) قبل دخول المقابلة.

---

## الجزء الرابع: التقارير والذكاء الاصطناعي (AI & Reporting)
*الهدف: تقديم قيمة حقيقية للمستخدم النهائي.*

- [ ] **Task 4.1: بناء محرك التقارير النهائي**
  - ربط نتائج المقابلة بـ Gemini API لتوليد تقرير نصي شامل عن سلوك المرشح.
- [ ] **Task 4.2: لوحة التحكم الحية (Real-time Dashboard)**
  - استخدام Supabase Realtime لتحديث الإحصائيات فور حدوث أي مقابلة.
- [ ] **Task 4.3: نظام الأرشفة والبحث**
  - تحسين صفحة التقارير لدعم البحث المتقدم والفلترة حسب "مستوى المخاطرة".
